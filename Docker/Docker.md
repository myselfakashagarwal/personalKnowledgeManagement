[[Docker]] 

 Docker is a framework for building, managing and running containers in which workloads reside. 
## Docker Architecture
Docker in nutsack works by manipulating process and aspects related to it. (container) Isolating a process and providing it with resources via cgroups, hiding the resources and process via namespaces , (image) building the process template aka the package with dependencies managed via overlay file system, drivers for managing networking, storage, registry etc.
