## Data modeling 
Data modeling is the process of structuring how data is defined, organized, stored, and interrelated, based on the analysis of data characteristics, business rules, and operational requirements, to establish an optimal representation for implementation i.e which is a set of predefined rules & constraints which define how the data is conceptualised, organised and data organisation is to be implemented.  
### Types of Data Model 
#### Conceptual Data Model 
The conceptual data model deals with defining the overview architecture how data is going to be related to each other, how data is grouped and organised. This category does not deal with implementation of any kind rather ideating the structural aspects. 
#### Logical Data Model 
The logical data model deals with how data organisation is going to be implemented in respect to concept, it revolves around how the schema to be implemented to organise, relate, handle and manage data with respect to need.
#### Physical Data Model 
Physical data model deals how data is stored onto underlying hardware and retrieval aspects such as optimisations.
